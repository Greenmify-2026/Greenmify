## 1. Objetivo da Sprint

Desenvolver funcionalidades de visualização e comparação de produtos, permitindo que os consumidores consultem informações detalhadas dos anúncios, conheçam os produtores responsáveis pelas ofertas e comparem diferentes produtos antes de tomar uma decisão.

## 2. Épico selecionado

**Épico 2 – Visualização e Informações dos Produtos**

## 3. Histórias relacionadas

- **US04:** Visualizar informações do produto.
- **US05:** Visualizar perfil do produtor.
- **US06:** Comparar produtos.

## 5. Definition of Done (DoD)

Uma história só pode ir para **Done** quando atender aos seguintes critérios:

- Funcionalidade implementada.
- Código revisado.

## 6. Execução da Sprint

Durante a Sprint 3, a equipe desenvolveu as funcionalidades de visualização e comparação de produtos.

A visualização detalhada permite que o consumidor consulte características importantes dos produtos. O perfil do produtor apresenta informações sobre o responsável pelo anúncio, enquanto a comparação facilita a análise entre diferentes ofertas.

### 6.1 Ocorrências registradas

Durante o desenvolvimento, foram considerados os cuidados necessários para garantir que as informações dos produtos e produtores fossem apresentadas corretamente e que a comparação entre diferentes ofertas funcionasse adequadamente.

### 6.2 Acompanhamento

O acompanhamento das histórias foi realizado por meio do quadro da Sprint, utilizando os estados:

- **To Do**
- **Doing**
- **Done**

Ao final da Sprint, todas as histórias foram movidas para **Done**.

## 8. Retrospectiva

### 8.1 O que funcionou

- A organização das informações facilitou a visualização dos produtos.
- O desenvolvimento das funcionalidades contribuiu para melhorar a experiência dos consumidores.
- Todas as histórias planejadas foram concluídas.

### 8.2 O que não funcionou tão bem

- A organização de diferentes informações exigiu atenção durante o desenvolvimento.
- A comparação entre produtos precisou de verificações para garantir uma apresentação clara.

### 8.3 O que podemos melhorar

- Padronizar a apresentação das informações.
- Testar a visualização em diferentes tamanhos de tela.
- Verificar a consistência dos dados dos anúncios.
- Realizar testes de comparação com diferentes produtos.
