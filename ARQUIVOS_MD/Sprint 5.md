## 1. Objetivo da Sprint

Desenvolver funcionalidades de gerenciamento de usuários e perfis, permitindo que consumidores e produtores criem suas contas, atualizem seus dados pessoais e completem as informações necessárias para utilizar a plataforma.

## 2. Épico selecionado

**Épico 5 – Gerenciamento de Usuários e Perfis**

## 3. Histórias relacionadas

- **US14:** Criar uma conta.
- **US15:** Editar dados do perfil.
- **US16:** Completar perfil de produtor.

## 4. Capacidade da Sprint

## 5. Definition of Done (DoD)

Uma história só pode ir para **Done** quando atender aos seguintes critérios:

- Funcionalidade implementada.
- Código revisado.
- Testes realizados.
- Critérios de aceitação atendidos.
- Documentação atualizada.
- Funcionalidade validada pela equipe.

## 6. Execução da Sprint

Durante a Sprint 5, a equipe desenvolveu as funcionalidades de cadastro e gerenciamento de usuários.

A criação de contas permite que novos usuários ingressem na plataforma. A edição de perfil possibilita a atualização dos dados cadastrados, enquanto o preenchimento do perfil de produtor permite apresentar informações relevantes sobre os responsáveis pelos anúncios.

### 6.1 Ocorrências registradas

Durante o desenvolvimento, foram considerados os cuidados necessários para garantir a validação dos dados informados pelos usuários e o funcionamento correto das operações de criação e atualização dos perfis.

### 6.2 Acompanhamento

O acompanhamento das histórias foi realizado por meio do quadro da Sprint, utilizando os estados:

- **To Do**
- **Doing**
- **Done**

Ao final da Sprint, todas as histórias foram movidas para **Done**.

## 8. Retrospectiva

### 8.1 O que funcionou

- O processo de criação de contas permitiu organizar o acesso dos usuários.
- A edição de perfil possibilitou a atualização das informações cadastradas.
- Todas as histórias planejadas foram concluídas.

### 8.2 O que não funcionou tão bem

- A validação dos dados exigiu atenção durante o desenvolvimento.
- O preenchimento dos perfis demandou verificações para garantir a consistência das informações.

### 8.3 O que podemos melhorar

- Testar diferentes situações de cadastro.
- Verificar a validação dos campos obrigatórios.
- Testar a atualização dos dados dos usuários.
- Revisar os controles de acesso às informações dos perfis.
